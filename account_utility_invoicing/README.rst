This module manages monthly utility charges for recurring services such
as rentals and shared facilities. Billing is handled manually for each
period, providing flexibility while enhancing operational efficiency

Usage
=====

to use this module, When it is time to bill utilities, users can follow
these steps:

1. Go to Utility > Account Utility > Utility Invoicing.
2. Create a new document and apply filters such as Utility Type and
   Customer, if you want to bill only selected utilities for that
   period.
3. Click **Retrieve Lines** to load utility records based on the
   selected filters.
4. In lines information:

   - For flat-rate charges, enter the amount in the Flat Rate field.
   - For metered utilities, enter the value in the Current field. It
     will calculate the charge automatically based on the Total Rate and
     the previous reading.

5. Review the information, then click **Confirm** and **Create
   Invoice**.
6. It will generate invoices grouped by partner, based on the account
   utility lines.
7. Review the generated invoices and proceed with the normal payment
   process.
