This module allows you to define custom receivable and payable accounts
per **invoice address** for a given customer or vendor.

When the option is enabled on the commercial partner, the account
defined on the selected invoicing address will be used instead of the
default from the parent company.

Use Cases / Context
===================

By default, all receivable and payable accounts on invoices are based on
the **commercial entity** of the partner. This means payment follow-up
and account tracking are done globally per customer/vendor, regardless
of the invoicing address used.

In some accounting or operational contexts, particularly when a customer
has multiple branches or divisions with separate accounting treatment,
it becomes important to:

-  Assign different receivable accounts to each invoicing address
-  Follow-up payments separately by branch
-  Keep financial reporting more granular

This module was developed to support this need while remaining
compatible with standard behavior.

Configuration
=============

To enable custom receivable and payable accounts by invoicing address:

1. Go to the commercial partner
2. Enable the checkbox **"Use custom accounts per invoice address"**.
3. For each **"Invoice Address"**:

   -  Set the desired **Receivable Account**
   -  Set the desired **Payable Account**

Usage
=====

1. Set up the customer with multiple invoice addresses.
2. Enable the "Use custom accounts per invoice address" option on the
   main customer.
3. On the invoice address, define a different receivable account.
4. Create an invoice using this invoice address.
