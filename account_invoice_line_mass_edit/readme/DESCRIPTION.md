This module allows to mass edit the lines of an invoice (customer invoice,
vendor bill, ...) from an editable list of lines.

This list is available from a smart button on the invoice form view. It
displays the product lines of the invoice, as well as the sections and notes
of the invoice, so that the user has the same vision as in the invoice.
Sections and notes are displayed there for information only: they are never
updated by the mass editing wizard.

By default, the mass editing wizard only allows to set the analytic
distribution of the selected lines. Other fields can be added, see the
*Configuration* section of this description.
