To use this module, you need to:

1.  Open a draft invoice.
2.  Click on the *Lines* smart button, it opens the list of invoice lines.
3.  Select the lines you want to update.
4.  Click on the *Mass Edit* button.
5.  In the wizard, set the value of the fields you want to update on the
    selected lines. Fields left on *Don't touch* are not updated.
6.  Click on *Apply*.
