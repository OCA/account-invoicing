This module extends the integration with Google Document AI to process invoices in "single_line_total" mode. 
It simplifies invoice creation and updates by removing detailed line items and taxes when applicable, 
allowing for quick and efficient invoice processing.

Configuration
=============

You can also configure the invoice processing behavior by setting google_ocr_invoice_mode to Single Line Total Mode in the Invoicing settings.

- Single Line Total Mode: The module extracts only the total amount of the invoice and creates a single invoice line with that amount.
