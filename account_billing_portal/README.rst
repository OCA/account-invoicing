This module adds a portal view for account billings. It allows users to
change the portal billing report template via a configurable setting.

   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.

Configuration
=============

To choose the billing portal report:

-  Go to *Invoicing → Configuration → Settings*.
-  Set a value in **Choose Billing Portal Report**. If set, this report
   will be used in the billing portal to show the billing and, when the
   billing is sent by email, as the attached PDF. If left empty, the
   standard report from the *Account Billing* module will be used
   instead.
