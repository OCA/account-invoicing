mean (email, Peppol, ...)

.. contents::
   :local:

Use Cases / Context
===================

- Odoo allows now to send mutliple attachments (through Peppol) but this
  should still be done manual processing, invoice by invoice.

- The idea is here to prepare invoices with their attachments to be send
  and then, allowing mass sending (through email, Peppol,...)

Usage
=====

- In each invoice, go to the 'Attachments to send' tab
- Select exisiting invoice attachments to embed them in the electronic
  sending
