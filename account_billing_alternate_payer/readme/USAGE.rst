#. Set an alternate payer on the customer invoices, in the *Other Info* tab.
#. Go to *Invoicing > Customers > Billings* and create a billing document for
   the alternate payer.
#. Press *Compute items*: the invoices payable by that partner are listed, with
   the column *Invoice Partner* showing who each invoice was issued to.
#. Validate the billing document and collect a single payment for all of them.
