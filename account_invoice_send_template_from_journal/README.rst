This module extends the Accounting functionality by allowing users to
define a default email template for each accounting journal.

A new field is added to the Accounting Journal (account.journal) that
lets users select an email template. When sending invoices from the
invoice journal, the selected template will be automatically available,
making it easier and faster to send invoices using a predefined format.
