1. Create a purchase order and add your products.  
2. Create a draft vendor bill from the purchase order **before any reception** (optional).  
3. Receive products (partial or full reception).  
4. On draft invoices with the **auto-update option enabled**, the invoice line quantities will automatically increase according to the updated `qty_to_invoice` from the PO lines.  
5. The PO line's `qty_to_invoice` is reset to zero for the quantities transferred to the draft invoice, preventing double billing.
