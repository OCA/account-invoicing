The auto-update feature for draft vendor bills is disabled by default. However, you can configure it at 2 levels: globally for all vendor bills or individually per draft vendor bill.


1. **Enable the feature globally (optional)**:

   - Go to **Accounting -> Configuration -> Settings**.
   - In the **Purchase -> Invoicing** section,
   - Check the option **"Auto-update draft invoice quantities from PO"**.  
   - This sets the default value for all newly created invoices.

2. **Enable the feature per invoice**:

   - On a vendor bill (draft), you can enable or disable the auto-update behavior individually.
   - The field **"Auto-update draft invoice quantities"** inherits its default value from the company but can be toggled per invoice.
