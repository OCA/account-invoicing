This module allows restricting the usage of taxes on invoice lines based
on the account code prefix.

A new field **Allowed Account Prefixes** is added on taxes. When set,
the tax can only be applied on invoice lines whose account code starts
with one of the configured prefixes.

This is useful in accounting contexts where multiple taxes share the
same rate but must be selected depending on the nature of the expense
(e.g. goods, services, investments).

Use Cases / Context
===================

In some accounting setups, multiple taxes may share the same rate (e.g.
21%) but differ in their reporting usage depending on the nature of the
expense.

For example:

- Accounts starting with 60 → goods
- Accounts starting with 61 → services
- Accounts starting with 2 → investments

Standard tax selection based solely on the rate is therefore not
sufficient to identify the correct tax.

This module introduces a simple and configurable mechanism to restrict
tax selection based on one or more account code prefixes.

Configuration
=============

1. Go to **Accounting → Configuration → Taxes**
2. Open or create a tax
3. Set the field **Allowed Account Prefixes**

This field accepts a comma-separated list of account code prefixes.

Examples:

- ``60`` → tax allowed only for accounts starting with 60
- ``60,61`` → tax allowed for accounts starting with 60 or 61
- ``2,60,61`` → tax allowed for investments and goods/services accounts
- spaces are ignored (``60, 61`` is valid)
- leave empty → tax allowed for all accounts

Usage
=====

1. Select or change the account on an invoice line
2. The available taxes are automatically filtered based on:

   - standard rules (company, country, usage)
   - the account prefix restrictions defined on taxes

Only taxes whose configured prefixes match the account code will be
proposed.

If no prefixes are configured on a tax, it remains available for all
accounts.
