This module allows you to configure whether tax lines with zero value
(e.g., 0% tax or externally computed zero amounts) should be kept in the
journal entries or not.

By enabling this behavior, the system will retain account move lines
related to taxes, even if the computed tax amount is zero. This is
particularly useful in countries where showing explicit 0% tax lines is
required for compliance or transparency.

Usage
=====

To use this module:

1. Go to *Invoicing > Configuration > Settings*
2. Enable the checkbox ``Keep Zero Line Taxes``
3. Create an invoice or bill and select a tax with 0%
4. Check Journal Items, and you will see a zero-value tax line created
