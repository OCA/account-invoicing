Use Cases / Context
===================

This module is useful when a company operates in a multi-currency environment,
and most of the account moves are made in a currency other than the main currency
set in the company settings.

Configuration
=============

Go to **Settings** → **Invoicing (Accounting)**:

- Select a currency available for the company in the **"Default Account Move Currency"** field
- Press the **"Save"** button to apply the changes

Usage
=====

Once the module is configured, the default currency will be set:

1. As the default value for the **"Currency"** field in the account moves (Invoices/Vendor Bills).
2. As the default **Journal Currency** in the Vendor Bill.
